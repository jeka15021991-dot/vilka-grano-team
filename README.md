# Команда VILKA · GRANO

Платформа обучения персонала. Сайт — папка `public/`, публикуется автоматически (GitHub Pages). Вход и данные — Supabase.

- `public/app.js` — приложение сотрудника и кабинет сервис-менеджера
- `public/characters.js` — персонаж Шефи: дизайн, эмоции, анимации
- `public/quest.js` — квест «Первая смена»
- `public/book-*.html` — «Вкусные книги»; содержимое зашифровано в `public/data/*.bin`, ключ выдаётся только вошедшим сотрудникам
- `tools/` — сборка: фото, вопросы, шифрование
